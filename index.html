🔥 WildfireWatch

Featured Stardance Project

WildfireWatch is an independent wildfire-monitoring web application that uses NASA FIRMS / VIIRS satellite fire-detection data to help users understand nearby wildfire activity, distance, detection confidence, and environmental context.

This is NOT an official NASA assignment — it's my independent Stardance project using NASA's open data.

💡 Why I built this: I've always been fascinated by how satellites see the Earth. When I saw NASA's FIRMS data, I realized I could build something that actually helps people understand wildfire risks near them. So I just started coding.

🔧 Tech / Data: NASA FIRMS, VIIRS, JavaScript, APIs, HTML/CSS

📌 Current Status: In active development (building, testing, breaking, fixing)
